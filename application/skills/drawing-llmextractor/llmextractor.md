# drawing-llmextractor

`drawing-llmextractor`는 도면이나 평면도 이미지에서 사용자가 지정한 주제(기둥, 문, 창, 엘리베이터 등)에 해당하는 객체를 Vision LLM으로 찾아, 원본은 그대로 두고 복사본 위에 빨간색 박스로 표시하는 스킬입니다. 주제가 벽이면 창틀·관찰창도 벽에 포함합니다. 주제가 창이면 기둥처럼 기호 하나씩 표시합니다.

## 목적

사용자가 준 **주제**와 **이미지 경로**만 받아, UI에서 고른 Vision 모델로 그 주제에 맞는 객체를 검출합니다. 결과는 두 파일입니다.

- `{원본이름}.{주제}.png` — 빨간 채움과 테두리만 그린 표시 이미지. 객체 이름은 적지 않는다
- `{원본이름}.{주제}.json` — 객체 이름, 원본 픽셀 좌표(`bbox_px`), 0~1 정규 좌표(`bbox_norm`), 사용한 모델 정보

에이전트가 모델을 임의로 고르지 않습니다. 환경변수 `UI_MODEL_NAME`이 UI 선택 모델이고, 사용자가 모델을 명시했을 때만 `--model`을 넘깁니다.

## 동작 방식

`extract_objects.py`가 한 장씩 처리합니다. 호출 형태는 앱의 `chat.extract_text`와 같습니다. 조각 PNG를 base64로 넣고 `get_chat().invoke`로 보냅니다.

1. **모델 설정.** `UI_MODEL_NAME`(필요하면 게이트웨이·가드레일 환경변수)으로 `chat.update`한 뒤 클라이언트를 만듭니다.
2. **조각 나누기.** 겹침 12%를 포함한 조각의 가로 또는 세로가 5000px를 넘으면 그 방향으로 더 나눕니다. 5000×5000 이하면 한 장으로 둡니다. 200만 픽셀로 미리 축소하지 않습니다.
3. **여백 건너뛰기.** 조각을 96×96 회색으로 줄여 잉크(밝기 245 미만) 비율이 0.2% 미만이면 Vision 호출을 하지 않습니다.
4. **병렬 검출.** 잉크가 있는 조각을 기본 4개씩 동시에 보냅니다. 프롬프트는 주제 원문을 번역하지 않고, 객체마다 꽉 감싸는 작은 bbox만 `<result>` JSON으로 받으라고 요구합니다. 좌표는 조각 기준 0~1입니다. 조각당 최대 5회 재시도합니다.
5. **좌표 복원과 필터.** 조각 좌표를 원본 픽셀로 되돌립니다. 조각 거의 전체(가로·세로 85% 초과)를 덮는 박스, 도면에서 너무 넓은 박스(가는 벽은 면적 20%까지, 그 외는 4%까지)는 버립니다.
6. **합치기.** 겹침 때문에 같은 객체가 두 조각에 잡히면 IoU 0.45 이상이거나 한쪽이 다른 쪽의 70% 이상 포함될 때, 더 작은 박스만 남깁니다.
7. **표시.** 원본을 RGBA로 복사한 뒤 반투명 채움과 테두리만 그립니다. `door` 같은 객체 이름은 이미지에 적지 않고 JSON `label`에만 남깁니다. 출력 경로가 입력과 같으면 저장을 거부합니다.

큰 도면은 Vision 호출이 여러 번이라 5분을 넘기기 쉽습니다. 스킬은 `nohup`으로 백그라운드 실행하고 로그를 짧게 확인하도록 안내합니다.

## 특징

- **해상도를 유지한 채 자른다.** 기존 `chat._prepare_image_base64`는 200만 픽셀을 넘으면 축소하지만, 이 스킬은 도면 선을 살리기 위해 그 축소를 쓰지 않습니다. `prepare_image.py`는 Bedrock Converse·Astra 한도(한 변 8000px, 32×32 패치 3만 개, PNG 3.75MB)를 넘을 때만 80%씩 줄입니다. 타일 상한 5000px는 그 한도 안에 들어오게 맞춘 값입니다.
- **좌표를 유연하게 해석한다.** 모델이 0~1이 아니라 픽셀이나 0~1000 스케일을 줘도, 조각 크기에 맞으면 정규화합니다. 너무 작은 박스(한 변 0.2% 미만)는 버립니다.
- **라벨이 비면 주제로 채운다.** JSON의 `label`이 없으면 `--topic` 문자열을 이름에 씁니다.
- **실행 환경이 고정되어 있다.** 비대화형 `python3`는 패키지가 없는 경우가 있어, `langchain`과 Pillow가 없으면 `python3.13`으로 다시 실행합니다. 이미지는 한 장당 bash 한 번이고, 응답은 한국어로 표시 PNG 경로, 객체 개수, 모델 이름을 알립니다. 객체가 0개면 주제를 바꾸거나 다시 돌리라고 안내합니다.
